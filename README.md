## ⚙️ 10. Installation and Setup

### Requirements

To run a static version of the website locally, you need:

* A modern web browser.
* A text editor such as Visual Studio Code.
* Git, if you want to clone and manage the repository.

### Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/cayr-com/cayr-com-store.git
```

### Navigate to the Project Directory

```bash
cd cayr-com-store
```

### Run the Website

For a basic static implementation, open `index.html` in your browser.

Alternatively, use a local development server, particularly if the website loads product data through JavaScript modules or local JSON files.

For example, using Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

The repository must exist and contain the website files before these instructions can be used.

### Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Navigate to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the appropriate branch, typically `main`.
6. Select the root directory if `index.html` is located there.
7. Save the configuration.

Once GitHub Pages finishes deploying, the site can be accessed through the published project URL.

For the repository name used in this example, the expected URL is:

https://cayr-com.github.io/cayr-com-store/

The URL will only become accessible after successful deployment.

## 🔐 12. Security and Privacy

Security and customer privacy are important considerations for any online shopping platform.

The following practices are recommended for production deployment:

* Use HTTPS for website connections.
* Keep dependencies and integrations updated.
* Protect customer information.
* Never expose private API keys or credentials in the repository.
* Use reputable and compliant payment providers if online payments are enabled.
* Publish an appropriate privacy policy.
* Provide transparent information about data collection and processing.
* Apply appropriate access controls to administrative services.

A static storefront does not automatically include secure payment processing, customer accounts, or order management.

Those functions require additional infrastructure and appropriate security controls.
